# RAFT — Optical Flow from Classical Methods to Deep Learning

A research-oriented computer vision project exploring optical flow, classical motion estimation, deep learning, and the RAFT architecture.

## Project Goals

- Understand optical flow and motion fields.
- Implement classical optical flow algorithms.
- Study the mathematics and architecture of RAFT.
- Build educational implementations of important RAFT components.
- Evaluate classical methods and pretrained RAFT using reproducible experiments.

## Technologies

- Python
- OpenCV
- NumPy
- Matplotlib
- PyTorch

## Project Status

Currently setting up the repository and beginning Stage 1: Optical Flow Fundamentals.
